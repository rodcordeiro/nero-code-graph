# Conventions

1. Preferir seam `CodeGraph` para testes de comportamento.
2. Não persistir JSON Graphify cru como canônico — normalizar `GraphDocument`.
3. Não registrar arestas AST com writers Nero (`nero_link_knowledge` etc.).
4. Aceite MVP: hops EXTRACTED vs golden; INFERRED tipado mas não bloqueante (salvo política).
5. Docs de produto em `docs/references/`; tickets em `docs/backlog/`.
