# Domain

Pack nero-core que materializa **grafo estrutural de código** para agentes:

- Generate / manage / query via MCP próprio
- Nós: file, class, method
- Arestas MVP: imports, calls (import-reachable)
- Proveniência: EXTRACTED / INFERRED (/ AMBIGUOUS)
- Storage: projeto e/ou mirror no Knowledge Nero (sem poluir `links:` operacionais)

Não substitui Nero Knowledge. Não faz parte do canônico Nero.
